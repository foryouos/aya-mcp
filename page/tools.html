设备与屏幕5 个 · 全部只读
工具权限说明
aya_list_devices只读列出已连接的设备与状态，标注 AYA 当前选中设备；调用其他工具前先确认 deviceId。
aya_device_info只读型号、品牌、Android 版本、分辨率与密度、内存存储、CPU 核心数、续航摘要。
aya_screencap只读截图并直接返回图片，默认缩放到 900px 宽、JPEG 质量 72，体积比原始 PNG 小 5–10 倍。
aya_ui_dump只读UI 层级树，节点含 bounds / center；支持过滤、字段裁剪、分页与快照复用，返回 snapshotId 与节点索引。
aya_current_app只读当前前台应用的包名与进程 pid。
交互10 个 · 2 只读 / 8 写
工具权限说明
aya_tap写点击屏幕：坐标、nodeIndex+snapshotId，或 text·id·desc 定位；默认点完立刻回传新界面；pressMs 可调按压时长（默认 20ms）。
aya_tap_text写按控件文本点击，等价 aya_tap + text；exact:false 子串匹配，index 选第 N 个同名控件。
aya_swipe写从 (x1,y1) 滑到 (x2,y2)，duration 默认 300ms，可开 withUi 观察结果。
aya_long_press写长按坐标或控件，触发控制条、自定义长按菜单与拖拽起点。
aya_gesture写注入一段可含多组 down/move/up 的事件流：长按拖拽、多段折线拖动、轻点唤醒后立即操作。
aya_key写发送按键：back / home / enter / recent / volume_up / power / dpad_* 等，也可传 keycode 数字。
aya_text写向焦点输入框输入 ASCII 文本，自动清空并临时切换到无联想输入法；中文请走 aya_shell。
aya_batch写一次调用串行执行最多 20 个动作，最后统一回传界面，专治 1–3 秒消失的瞬时控件。
aya_wait_for只读等待控件出现或消失；默认由无障碍事件唤醒（界面一变立刻复核），事件不可用时退回轮询。
aya_ui_watch只读订阅窗口/内容/滚动事件直到命中条件，设备端按 80ms 合并；用于「等界面动起来」这类没有固定控件的场景。
应用管理8 个 · 2 只读 / 6 写
工具权限说明
aya_list_packages只读包名列表（apk 路径、是否系统应用），支持关键字过滤与仅看第三方应用。
aya_app_info只读版本号、sdk、安装/更新时间、启用状态、运行状态与 pid。
aya_start_app写启动 Launcher Activity，默认等前台切换，也可等指定控件出现；未安装返回 NOT_FOUND。
aya_stop_app写am force-stop 强制停止应用，进程立即被杀死。
aya_clear_app_data写pm clear 清空应用数据与缓存，等价系统「清除数据」，不可撤销。
aya_set_app_enabled写pm enable / pm disable-user 启用或禁用应用，禁用后桌面入口消失。
aya_install_app写安装 apk（本机路径会自动 push），默认 -r 覆盖并保留数据，支持 downgrade / grant。
aya_uninstall_app写卸载应用；keepData:true 时只删 apk 保留数据，卸载后回查确认结果。

工具权限说明

工具权限说明
aya_logcat只读logcat 快照，级别/标签/关键字/pid/since 过滤在设备端完成，附带崩溃摘要。

串口11 个 · 5 只读 / 6 写
工具权限说明
aya_serial_list_ports只读列出主机串口（COM3 / /dev/ttyUSB0），与 adb 端口转发的 aya_list_ports 无关。
aya_serial_status只读连接参数、已收行数与字节数、是否暂停、会话日志文件路径。
aya_serial_logs只读按来源、关键字或正则、fromSeq 增量读取串口日志，返回带时间与来源的行。
aya_serial_wait只读等待新日志命中关键字（如 boot_completed），只匹配调用之后到达的行。
aya_serial_stages只读按 bootloader / kernel / android / other 返回阶段切分与耗时，快速定位卡在哪个阶段。
aya_serial_open写打开串口接收启动/内核/Android 日志，8N1，默认 115200。
aya_serial_close写关闭串口，已收日志仍保留在缓冲区与日志文件中。
aya_serial_write写向串口写入数据（如向 bootloader 发 reboot），默认追加 \r\n。
aya_serial_clear写清空缓冲区并新建会话日志文件，串口保持连接。
aya_serial_pause写暂停日志推送，设备端仍在接收并落盘，无需关闭串口。
aya_serial_resume写恢复日志推送，暂停期间产生的日志仍可从缓冲区读到。

工具权限说明
aya_performance只读CPU 各核负载与温度、内存占用、电量、开机时长、前台应用帧率。

录屏与投屏5 个 · 1 只读 / 4 写
工具权限说明
aya_start_recording写设备端 screenrecord 后台开录，立即返回；默认 180 秒上限，可设码率与分辨率。
aya_stop_recording写停止录制并拉回本机，返回路径、大小、时长；省略 localPath 存到 aya-mcp/。
aya_recording_status只读是否在录制、已录时长、剩余时长、设备端文件大小。
aya_cast_window写打开 / 关闭 / 重启 AYA 投屏窗口，可传 deviceId 把窗口固定在指定设备。
aya_cast_settings写读取或修改投屏码率与最大边长，restart:true 立即重启窗口生效。
没有匹配的工具，换个关键字或切回「全部」试试。
定位与快照：aya_ui_dump 返回的 i 是未过滤完整树的 DFS 前序号，过滤只减少返回节点、不改变 i；snapshotId 60s 过期，任何输入类工具执行后立即失效，返回 STALE_SNAPSHOT 时重新 dump 即可。aya_stats 可查看每个工具的实际耗时与 dump 复用率。
